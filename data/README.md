# Data

| File | What it is | Source |
|---|---|---|
| `CO2_Emissions_Canada.csv` | **Main dataset.** 7,385 vehicles from 42 makes, 2014 to 2020 model years (the file has no model-year column). | [Kaggle: CO2 Emission by Vehicles](https://www.kaggle.com/datasets/debajyotipodder/co2-emission-by-vehicles), compiled from the Government of Canada ratings |
| `canada_2021_2026_bmw_mercedes.csv` | Newer cars: every BMW and Mercedes-Benz row for model years 2021 to 2026 (626 rows), unchanged. | Government of Canada, [Fuel consumption ratings](https://open.canada.ca/data/en/dataset/98f1a129-f628-4ce4-b24d-6f16bf24dd64): files "2015-2024 Fuel Consumption Ratings" (2021-2024 rows), "2025 Fuel Consumption Ratings" and "2026 Fuel Consumption Ratings", downloaded 24 Nov 2026 |
| `canada_ev_2012_2026_bmw_mercedes.csv` | Electric cars: every BMW and Mercedes-Benz battery-electric row (166 rows), unchanged. Ratings are in kWh per 100 km. | Same portal, file "Battery-electric vehicles 2012-2026", downloaded 24 Nov 2026 |
| `eu_obfcm_bmw_mercedes_2021_2024.csv` | EU real-world (on-board fuel meter) against laboratory CO2 for BMW and Mercedes-Benz fleets, 2021 to 2024. | Supplied with the first version of the project (2024_Cars_Aggregated.csv) |
| `emission_factors.csv` | Factors used by the estimator, the recommendations and the everyday comparisons, each with its source. | See the file |
| `processed/` | Generated by `python python/1_prepare_data.py`. | |

The two Government of Canada files are filtered copies: only the BMW and Mercedes-Benz rows
were kept, and nothing else was changed. The data is published under the Open Government
Licence - Canada.
